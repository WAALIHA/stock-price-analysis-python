# Stock Price Analysis and Forecasting in Python

## Project Overview

This project demonstrates the use of Python for quantitative finance and stock market analysis. Historical stock price data was downloaded using the Yahoo Finance API and analyzed using various statistical and financial techniques.

The project includes data visualization, return calculations, volatility analysis, moving averages, risk-return comparisons, and a simple machine learning forecasting model.

---

## Objectives

- Download real stock market data
- Visualize stock price movements
- Calculate daily returns
- Measure stock volatility
- Analyze moving averages
- Identify best and worst trading days
- Compare multiple stocks
- Compare returns and risk
- Calculate risk-return ratios
- Build a simple stock price forecasting model

---

## Technologies Used

- Python
- yfinance
- pandas
- numpy
- matplotlib
- scikit-learn

---

## Project Files

### 01_download_data.py
Downloads historical stock data from Yahoo Finance.

### 02_plot_stock_price.py
Plots historical stock prices.

### 03_daily_returns.py
Calculates daily percentage returns.

### 04_volatility_analysis.py
Measures stock volatility using standard deviation.

### 05_moving_averages.py
Calculates and plots 20-day and 50-day moving averages.

### 06_best_and_worst_days.py
Finds the best and worst trading days.

### 07_compare_multiple_stocks.py
Compares Apple, Microsoft and Nvidia stock prices.

### 08_compare_returns.py
Compares total returns between stocks.

### 09_risk_vs_return.py
Compares risk and return metrics.

### 10_risk_return_ratio.py
Calculates risk-return ratios.

### 11_simple_price_forecast.py
Uses Linear Regression to forecast stock prices.

---

## Key Findings

### Apple (AAPL)

- Total Return: 35.56%
- Average Daily Return: 0.13%
- Volatility: 1.41%

### Microsoft (MSFT)

- Total Return: 14.50%
- Volatility: 1.26%

### Nvidia (NVDA)

- Total Return: 178.87%
- Volatility: 3.31%

Nvidia produced the highest return but also carried the highest level of risk.

---

## Forecasting Model

A simple Linear Regression model was used to predict stock prices.

Model Performance:

- RMSE: 2.9

The model closely tracked actual Apple stock prices, demonstrating basic predictive capabilities.
